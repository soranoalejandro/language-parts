# Description
Philosophy and implementation for a new programming language, made modular and with implementations in more than one base programming language when possible.
# Goals
one or two language must come out as result, sharing many of their constructs in order to be used alongside each other whit less friction.
# Concept
The languages aimed here are conceived as 'tools for the automation of code generation', that meaning, one of them must be used to automate machine code generation, and the other as a second, higher tier language, making use of the first to offer even higher abstraction.
Almost sure that 2 languages would come out of this, under the concept of one being the tool needed to construct the other one.
